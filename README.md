# GJ Christmas 2026

格致中學 2026 年 12 月 18 日聖誕活動的 Three.js 互動邀請卡原型。

## 開發

需要 Node.js 22.12+（或 20.19+）與 npm。本次環境使用 Node.js 24。

```sh
cd /workspace/115Christmas
npm ci
npm run dev
```

本機開啟終端顯示的開發網址；同一區域網路的手機可使用電腦 IP 搭配 5173 埠測試（需允許防火牆）。雲端環境的預覽方式依平台支援而定。

```sh
npm run build
npm run preview
```

正式部署使用 `dist/`。不需要資料庫、登入、API 金鑰或環境變數。Google Fonts 僅用於可選字型，無法連線時使用系統字型。

## GitHub Pages

`vite.config.js` 已設定 `/115Christmas/` 路徑。到 GitHub 儲存庫的 Settings → Pages，將 Source 設為 **GitHub Actions**。推送至 `main` 或手動執行 Actions 中的 Deploy Christmas invitation to GitHub Pages，即會建置並部署。

預期網址：`https://leeyanyu.github.io/115Christmas/`。請以 Actions 成功結果與實際 HTTP 回應確認部署完成。儲存庫若為私人，Pages 可用性取決於 GitHub 方案；部署網站可能對外公開。

## 手動驗收

1. 使用支援 WebGL 2 的手機或桌面瀏覽器開啟，確認深藍場景、立體樹及金色裝飾；開場自動播放彩帶匯聚，樹木接著由底向上彈性展開。
2. 滑鼠 / 單指水平拖曳，確認可以從不同角度觀看，手機仍可垂直捲動。聚焦畫布後亦可按左右方向鍵。
3. 開場結束後按「再次喚醒聖誕樹」，確認按鈕停用避免重複啟動，燈串由下向上點亮，金色光點螺旋上升，約 8.5 秒點亮完成後，聖誕樹再旋轉一圈、移到中央並放大，約 13 秒顯示 `Light Up Christmas 2026` 並恢復拖曳。
4. 旋轉手機或調整視窗，確認畫面比例與操作正常。按鈕或重新整理皆可重播。

像素比例上限 1.75，樹周圍粒子由 18 顆漸增至 180 顆、甦醒光點 64 顆，沒有陰影貼圖或後製 Bloom。尊重減少動態效果偏好，停用背景漂移並降低光點亮度；主要點亮動畫保留。未提供 WebGL 2 時顯示操作提示。

## 目前視覺與動畫

聖誕樹採第一版的九層立體枝葉、金球、燈串及頂端星星。開啟頁面自動播放約 13 秒序列，完成後可按按鈕重播：

1. 五條寬幅金色緞帶沿手繪風格的大 S 型曲線，從畫面外快速飛入；約 1.2–1.5 秒抵達樹底附近。
2. 彩帶有柔和緞面光澤，轉彎處以連續切線及密集取樣保持圓順；約第 2 秒起漸淡，約 4.3 秒完全淡出，搭配少量尾端光粒子。
3. 約第 1.7 秒起，枝葉由底往上展開並彈性回彈，燈串與星星接續點亮。
4. 樹周圍由 18 顆柔光粒子逐漸增加至 180 顆，約 15 秒達到上限，之後維持緩慢漂浮。重播會重設粒子的出現進度。

光暈由自訂 shader 繪製，不使用 Bloom。開場獨立 renderer 的像素比例上限為 1.25。重播、轉向及捲動時更新樹底落點。減少動態效果偏好會略過光流及消散粒子，並使用平順枝葉展開。

### 舞台揭幕

點亮完成後，以 4.2 秒平滑轉場將聖誕樹與底座旋轉一圈，同步擴展畫布、置中取景並放大。原邀請文字退場，祝福文字與重播按鈕位於下方；鏡頭依視窗長寬比保留完整星星及底座。轉場期間暫停手動旋轉，結束後恢復。重播會回到原本排版、相機與樹木姿態。減少動態效果偏好會使用短轉場並略過整圈旋轉。

舞台轉場期間固定使用最終尺寸的繪圖緩衝區，只調整畫布顯示位置、大小及相機。ResizeObserver 僅標記尺寸變更，實際緩衝區更新統一於動畫迴圈繪製前執行，避免在繪製後清空畫面。驗證轉場時應抽查旋轉中的多個時間點，確認樹始終可見，而非僅確認轉場完成狀態。

## 原版美術上的互動加強

保留原本樹模型、深綠／金色材質、背景、燈光配置與開場運鏡；未新增套件或 Bloom。

- 手動旋轉保留 OrbitControls 與慣性。旋轉時燈串出現溫和暖金光暈，星星略微增亮，停轉後漸暗。開場的樹身旋轉也有相同回饋。
- 開場完成後閒置 10 秒，樹身自動以約 8 秒轉完一圈並發光，之後等待 10 秒再重複。按下、觸碰、鍵盤或滾輪操作立即中斷；操作中、隱藏分頁及重播時重設計時。
- Raycaster 點擊／輕觸樹面產生 12 顆香檳金／暖白星光，向外柔和漂浮減速，約 1–1.4 秒消退；低效能模式為 8 顆。移動超過 7 CSS px 不視為點擊，多指或取消不觸發。
- 旋轉速度帶出少量弧形星軌，停下後自然消退。互動粒子共用固定容量池（96 顆，低階裝置 48 顆），持續低幀率時降低發射率。
- 減少動態偏好停用自動旋轉與星軌；點擊只產生 8 顆原地淡出的光點，旋轉暖光降低。偏好切換會清除互動粒子。

`rotation-glow.js` 管理旋轉暖光與閒置展示，`tree-interaction.js` 管理點擊判定及星軌發射，`interaction-particles.js` 管理固定粒子池。`starlight-style.js` 的色票僅用於新增光效，不影響原版美術。

驗證：`npm run build`、`node --test tests/*.test.js`。瀏覽器驗收應包含桌機滑鼠、手機觸控、點擊與拖曳區分、放手消退、閒置展示及中斷、重播、直橫向尺寸，以及減少動態模式。

### 等待時的小彩蛋

- **轉出星星**：短時間快速來回拖曳，累積約半圈以上的有效旋轉能量，樹頂就會散出一波五角星。慢慢轉、閒置自轉及放手後的慣性不會觸發；星星彩蛋有 5 秒冷卻。
- **星星召雪**：連點／輕觸樹頂星星三次，每次間隔不超過 1.2 秒，開始約 10 秒的柔和飄雪。星星四周有小範圍容錯，側面觀看也能觸碰。再次召雪需等待前次結束與短暫冷卻；拖曳及多指不當作點擊。
- 一般樹面點擊仍會出現小星光；手動旋轉暖光、閒置展示和原版外觀保持不變。重播會清除彩蛋與計數。

`play-triggers.js` 管理累積能量、連點與冷卻；`play-rewards.js` 使用固定緩衝區繪製星星及雪，無須新增套件。彩蛋粒子上限 192 顆（低階裝置 96 顆），低幀率時另減少發射數。減少動態模式保留驚喜的提示與靜態淡光／雪點，不播放噴射或飄落。切換偏好時清除正在播放的效果。

### 彩蛋空間感與 GJ 落款

雪與星星採三組尺寸及個別透明度，搭配透視縮放、距離淡化與輕微明暗變化；近景雪花較大柔軟，背景雪點較細淡，仍保留原先數量上限與減少動態設定。深度以相機至主體的距離為基準，手機取景也能維持前後層次，不新增後製。

底座上表面以小尺寸香檳金襯線字樣嵌入 GJ（`src/scene/pedestal-signature.js`），無牌面、外框或立起的線條；字樣平貼並跟隨樹木旋轉。字形使用已安裝 Three.js 隨附 Optimer 的 G/J 子集，授權保留於 `src/scene/fonts/LICENSE.txt`，無需額外套件或外部字型請求。原樹型、材質色彩、底座與邀請版面保持原樣。

旋轉暖光會同步讓背景的深藍漸層加深，停轉後平滑恢復；由 `rotation-atmosphere.js` 管理獨立背景層，不改變文字、按鈕或樹木本身的透明度。手動、慣性及閒置自轉均適用，重播會重設，減少動態模式降低變化強度。
